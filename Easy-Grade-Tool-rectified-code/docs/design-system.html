Design system

One palette, three radii, one typeface, one definition per component. Everything below comes from src/styles.

Colour

Brand indigo-slate #4C5985 (the logo colour) on slate neutrals. Values flip automatically in dark mode; components never hard-code a colour.

Type

Plus Jakarta Sans only. Numbers use tabular figures instead of a monospace face. 12px is the smallest text.

Heading 1: 28 to 36px / 800

Heading 2: 20 to 24px / 700

Heading 3: 17px / 700

Heading 4: 15px / 700

Body text is 16px with a 1.6 line height, set in ink on surface. Long passages stay under about 70 characters per line so they are comfortable to read.

Secondary text, 14px in ink-2.

Caption, 12px in ink-3 (the minimum size).

Buttons and chips

Pill shaped, 44px minimum height (48px on touch screens). Three levels of emphasis; one primary action per view.

Form fields

One look for input, select and textarea: 48px tall, 12px radius, a 3:1 border, a single brand focus ring.
