## The honest finding first

Your site's font family did not need changing, because it is already
Dribbble's: **Mona Sans**, self-hosted since the premium redesign (SIL Open
Font License 1.1, variable weight 200–900, 101 KB). Dribbble's product UI
typeface is Mona Sans — its wordmark font is a different, commercial font
and was deliberately not copied; it is a logo, not UI text.

What made Dribbble look "a little thin" next to your site was weight, not
family. A live read-only check of dribbble.com confirmed the direction
(headlines read as full bold, not extra-bold/black; nav and body read
regular), but that browser could not expose computed styles — no DevTools
or JavaScript execution — so no exact pixel values could be read from the
live page. Nothing here is presented as a measured Dribbble value. The
change follows Dribbble's documented system (Mona Sans 400–800, headlines
bold-not-black, body/nav regular) and your "thin" direction.

## What changed

One new layer, `src/styles/dribbble-type.css`, imported last in `main.tsx`.
No component file was edited, so the change is uniform across every tool,
page, and card. Sizes, line-heights, colours, and layout are untouched —
only weight, display tracking, and smoothing:

| Before | After | Where it shows |
|---|---|---|
| 900 / 800 extra-bold | 700 bold | Banner and display titles |
| 700 bold | 600 semibold | Headings, buttons, strong labels |
| 600 semibold | 500 medium | Card titles, links, labels, tabs |
| 500 medium | 400 regular | Secondary and meta text |
| 400 regular | 400 (unchanged) | Body text |

Concretely: banner titles step 800 → 700 with tracking opened from -0.04em
to -0.02em; h1 stays 700 (Dribbble headlines are full bold) with the same
more open tracking; h2 → 600; h3 → 600; h4–h6 → 500; `b`/`strong` and table
headers → 600; body gains antialiased font smoothing, which makes strokes
read thinner, especially on macOS. Relative hierarchy is preserved — the
heaviest thing on a page is still the heaviest, it is just lighter.

How it wins: the file is unlayered and imported last, so it beats
Tailwind's layered utilities and every earlier type rule at equal
specificity. That matters because the heaviness was systemic: 402
`font-semibold`, 335 `font-bold`, and 45 `font-extrabold` uses across
components, plus 700/800 rules in five stylesheets. Editing those one by
one would have been a 40-file diff for the same result.
