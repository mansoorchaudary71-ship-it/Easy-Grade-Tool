# LUMEN — full UI/UX makeover, light mode only (2026-10-26)

Unzip over the repo root (paths match), then: `npm run lint && npm run build`.
No calculator maths, copy, routes, URLs or schema changed. `scripts/sitemap-hashes.json`
is regenerated by the build because class strings in prerendered HTML changed.

## 1. Audit: what was actually flat or wrong
- Eight stacked CSS layers (premium, coursera, nova, nova2 ...) fought each other, and a
  full dark theme (3 modes, `.dark` rules, ~2,500 `dark:` classes) doubled every surface.
- Near-black buttons (#1A1C1E, slate-900, #0A0A0B), a dark formula block, a dark toast
  and dark modal scrims worked against a bright, airy feel.
- Phones had a hamburger and a small search icon at the TOP only: no thumb-reach navigation.
- Cards used 16/20/24/28px radii depending on file; fields were white-on-white.

## 2. Best-of-7, merged into one system (src/styles/lumen.css)
| Reference | Extracted | Applied to |

| Dribbble | Frosted floating header, grey search pill, solid pill CTA | Header (`.lm-chrome`), search pill |
| Calendly | Floating white cards, layered soft shadows | One card surface (`--lm-shadow-1/2/3`), banner |

| ClassDojo | Optimistic pastel accents (peach, lilac, mint), decoration only | Hero aurora, newsletter + escape-hatch washes |
| Intercom | Airy canvas, product inside the hero | Canvas wash; existing hero planner kept |

## 3. Global styles (100% light)
- Primary `#2457F5` (hover `#1A41C9`, soft `#EEF2FF`, line `#D5DEFF`); white text on it = 5.6:1.
- Ink `#0E1424`, ink-2 `#2C3550`, muted `#5A6480`; canvas `#FAFBFF` + pale aurora; hairline `#E3E8F6`.
- Radii 12 / 18 / 24 / 32. Mona Sans; display tracking -0.032em to -0.045em.
- Motion: aurora drift, eyebrow pulse, spring-lift on buttons/chips/cards, dock entrance,
  scroll-driven reveal (`animation-timeline: view()` where supported). All respect
  `prefers-reduced-motion`.

## 4. What changed
- **Dark mode removed everywhere**: `ThemeContext` is light-only (clears any old `.dark`
  class and stored preference); theme toggle removed from the Navbar and the command
  palette; all `.dark` / `prefers-color-scheme: dark` CSS deleted; all `dark:` Tailwind
  classes removed; `<meta color-scheme>` is `light`; one `theme-color` (#FAFBFF, manifest matches).
- **New** `src/components/MobileDock.tsx`: floating bottom dock below lg (Home, Grade, GPA, Search).
  Mounted in `SiteHeader.tsx`; hidden in print.
- **New** `src/styles/lumen.css`, imported last in `main.tsx`.
- `tools/ui.ts`: shared tool tokens (24px cards, soft-fill fields, glow primary, gradient result box).
- Footer newsletter band, update toast, methodology formula block, install button, FAQ/How-to
  badges: dark or black fills replaced with white / brand blue.
- Brand blue literals (#0056D2 family) re-pointed to Lumen blue across components and CSS
  (the Logo mark is intentionally untouched so it still matches the public icons).
