# Easy Grade Tool: merge notes (batches 1 and 2)

1. Unzip over the repo root (same paths overwrite).
2. Run:  sh cleanup.sh      (removes dead copies and relics; read it first, it only touches files nothing references)
3. Run:  npm run lint && npm run build     (build = math checks + page checks + vite build + prerender + sitemap + launch checks)
4. Commit and push.

Notes
- New scripts/verify-scale-pages.ts is part of `npm run build` and `npm run verify:math`.
- New share cards live in public/og-cards/. Regenerate any time with: python3 scripts/generate_og_cards.py
- public/sw.js and public/manifest.json are generated by VitePWA; delete them after confirming dist/ has both.
