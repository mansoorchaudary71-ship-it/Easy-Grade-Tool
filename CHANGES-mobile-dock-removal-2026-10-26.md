# CHANGES — Remove the MobileDock rail (2026-10-26)

## What was wrong

On the live site, a vertical Home / Grade / GPA / Search icon stack rendered at the
left of every page, above the tool-name banner, on every device and every screen
width. It was not a browser extension: it is the site's own `<MobileDock />`
component (`src/components/MobileDock.tsx`), mounted in `SiteHeader.tsx` above
`<Routes>`, so it shipped in every page's HTML.

Why it looked like a raw vertical list instead of the intended floating bottom
pill: its stylesheet, `src/styles/lumen.css` (`.lm-dock`, hidden on desktop and a
fixed bottom pill below 1023px), is never imported anywhere — not in
`src/main.tsx`, not in `src/index.css`, not in any other stylesheet. With no
`.lm-dock` rules loaded, the dock fell back to an unstyled list: vertical,
in-flow, at the left, directly above the banner. That is exactly what the
screenshots showed, and why it appeared on different devices — it is in the
shipped HTML, not in any one browser.

## What changed (upload these to the repo root, then push)

- `src/components/SiteHeader.tsx` — the `<MobileDock />` render and its import
  are removed; the header is now just the sticky header row (`Navbar`). Props
  are unchanged, so nothing else that uses `SiteHeader` needs to change.
- `scripts/sitemap-hashes.json` — regenerated by the build (as usual).

## What was deliberately left alone

- `src/components/MobileDock.tsx` is now unused but still in the repo. Deleting
  it is optional housekeeping — it renders nothing on its own. Delete it at
  leisure if you want the dead file gone.
- `src/styles/lumen.css` is still unimported (its pre-existing state). It also
  carries the `.lm-chrome` header-surface rules, but importing the whole file
  would restyle other elements too, so that is a separate decision, not part
  of this removal. Nothing in this package depends on it.

## What still navigates on phones

Removing the dock does not strand mobile visitors: the hamburger drawer and the
header search still work, and every dock link (Home, Grade calculator, GPA
calculator, Search) is also reachable from the header navigation and the search
palette.

## Verification

- Clean build, exit 0, launch audit 17/17 passed.
- Before the fix, the built semester page HTML contained the dock
  (`lm-dock-item`); after the fix, the built home and semester pages contain
  zero `lm-dock` / "Quick navigation" matches, while the header Main nav and
  the banner title are intact.
