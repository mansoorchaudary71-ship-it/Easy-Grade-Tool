### 6. Security headers ×4 (Referrer-Policy, X-Content-Type-Options,
Content-Security-Policy, X-Frame-Options — all "missing" on 100% of URLs)
GitHub Pages cannot send custom response headers, so no code change can add them
while the site is hosted there. Mitigations already in place:
- **Referrer-Policy** is already delivered on every page via
  `<meta name="referrer" content="strict-origin-when-cross-origin">` in index.html —
  the crawler only checks the HTTP header, which is why it still flags it.
- **All four headers are already written** in `public/_headers` in this repo. They
  activate automatically if the domain is put behind Cloudflare (free) — that is
  the one-step fix for this whole group.
- **X-Frame-Options is deliberately NOT set to DENY/SAMEORIGIN**: that would break
  the /for-schools/ embed programme, which exists so other sites can frame the
  calculators. The CSP in `_headers` likewise omits frame-ancestors on purpose.
