# Easy Grade Tool

Free grade calculators (quick grade chart, weighted grade, final exam, test grade, curve, letter grade, GPA, CGPA) built with React 19, Vite 8, Tailwind v4 and TypeScript. The production site is a static, prerendered build hosted on GitHub Pages.

## Requirements

Node 22 (see `.nvmrc`). Install with `npm ci`.

## Commands

| Command | What it does |
|---|---|
| `npm run dev` | Dev server (`tsx server.ts`) |
| `npm run build` | Math and scale checks, Vite build, prerender, sitemap, build info. Then `postbuild` runs `verify-launch` (CHK-01 to CHK-17) |
| `npm run verify` | Re-run the launch checks against `dist/` |
| `npm run verify:math` | Grade math and generated-page checks only (fast, no build needed) |
| `npm run verify:selftest` | Injects known violations and confirms the launch checks catch them |
| `npm run lint` | `tsc --noEmit` |
| `npm run clean` | Remove `dist/` and `server.js` |

## Deploy

Pushing to `main` runs `.github/workflows/deploy.yml` (`npm ci`, `npm run build`, upload `dist/`, deploy to GitHub Pages). The custom domain is set in `CNAME`.

## Environment variables

All optional, see `.env.example`: `VITE_SITE_URL`, `VITE_CONTACT_EMAIL`, `CONTACT_EMAIL`, `FEEDBACK_WEBHOOK_URL`, `RESEND_API_KEY`, `FEEDBACK_DESTINATION_EMAIL`, `VITE_FORM_ENDPOINT`.

## Notes

- GitHub Pages ignores `public/_headers`. Security headers need a CDN in front. See `docs/SEO-OPS.md`.
- The service worker and web manifest are generated by VitePWA. Do not add `public/sw.js` or `public/manifest.json`.
- Old design notes are kept in `docs/notes/`.
