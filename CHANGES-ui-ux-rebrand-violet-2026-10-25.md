# Visible rebrand — violet + serif + warm canvas (2026-10-25)

Upload these files to the repo root (same top-level layout as the repo),
commit, push. This REPLACES the previous blue identity: the last package
(same blue, same shapes) verified live but looked unchanged, so this one
changes colour and font style outright, as requested. Calculator layout,
copy, URLs, and behaviour are untouched — only colour, type, and surfaces.

## The new system (one unit, from the best of the 7)

- **Primary — violet** (ClassDojo/Canva violet, deepened so white text
  stays readable): `#6D28D9` light, `#A78BFA` dark, hover `#5B21B6` /
  `#C4B5FD`. Every old blue now resolves to it: the teal + blue utility
  scales, every `#0056D2` / `#00419E` / `#4F9CFF` literal, the footer
  gradients, the focus rings (including the `!important` ones in
  index.css, which previously overrode everything), and the skip-link
  outline.
- **Canvas — warm off-white `#FBF9F6`** (Calendly) with white floating
  cards, instead of flat white-on-white.
- **Display type — serif headlines** (Typeform/Calendly editorial serif):
  banner titles, section H2s, panel + newsletter titles now render in a
  system serif stack (Iowan Old Style / Palatino / Georgia — no new font
  download, offline-safe). All UI text — buttons, inputs, cards, body —
  stays Inter.
- **Dark plum footer** (Typeform plum-black): footer gradient is now
  `#1E1727 → #4C1D95` with a violet gradient button.
- **Fields** (Calendly): white fill + slate border + violet focus ring.
- **Kept from before:** pill buttons, 16px cards, hairline borders,
  Dribbble-style header structure (now violet), category-card hover lift,
  tracked uppercase eyebrow kickers.
