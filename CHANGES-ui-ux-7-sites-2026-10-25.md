# UI/UX unification — best of 7 reference sites, one system (2026-10-25)

Upload these files to the repo root (same top-level layout as the repo),
commit, push. Nothing here changes any calculation, copy, URL, or content —
only colour, radius, spacing, and hover/focus treatment.

## What was compared (all checked live, read-only, 2026-10-25)

Intercom, Calendly, Typeform, Canva, Asana, ClassDojo, Dribbble — header,
hero, buttons, cards, forms, type, spacing, footer, mobile patterns each.

## The unity rule

Every picked pattern is rendered in the site's ONE blue (#0056D2 light /
#4F9CFF dark) and ONE radius system (16px cards, pill buttons), so the site
reads as one product, not seven. What was picked, and from where:

- **Buttons — one pill triad** (Typeform's triad + Asana/Calendly pills):
  solid brand-blue primary, white hairline secondary, plain arrow link.
- **Cards — one card** (Calendly floating cards + Canva 12–16px + Asana
  hairline): white, 16px radius, hairline border, soft shadow. Link hubs
  (homepage category cards) lift 2px on hover, like Canva template cards
  and ClassDojo role cards. Calculator forms never lift.
- **Fields — neutral grey fill, white + brand-blue ring on focus**
  (Typeform focus clarity, Dribbble's #F3F3F4 field grey).
- **Type — tracked uppercase eyebrow kickers** (Typeform/Asana/Calendly),
  tight headline tracking (Intercom/Asana), one section rhythm.
- **Tabs — pill switcher with solid-blue active state** (Asana).
- **Header — unchanged** (Dribbble-style header from the previous package).

## What was deliberately NOT copied

Copying these would have broken unity: Canva's multi-hue gradients,
Typeform's lime + dark plum canvas + serif display, ClassDojo's purple +
mascots, Asana's coral/lavender, Calendly's navy, Intercom's black buttons,
Dribbble's pink search button, and product-specific flows (chat launcher,
booking flows). Dark mode keeps resolving to the same blue family via the
token aliases in coursera.css.
