# Tool-banner rings — thin circular lines (2026-10-26)

**Upload this zip alone to the repo root** (folders are already at the top level).
Applies on top of the NOVA overhaul, whether or not the NOVA II zip has been
uploaded yet — the two changed components are identical in both states.

## What changed

The tool-name banner — the card that carries every tool's name, badge,
description, and journey stepper — used to sit over flowing wavy SVG lines.
Those lines are gone, replaced by thin circular lines:

- **New `rings` variant in `DecorLines.tsx`:** 6 concentric circles centred on
  the banner's right edge (radii 50–325), so the banner shows sweeping
  circular lines coming in from the right, in the same position and size the
  waves used.
- **Thinner, as asked:** stroke width **1**, down from the waves' 1.5 (and well
  below the squiggle's 2.5). Same blue as before (`.cs-lines`), same opacity,
  full dark-mode support — only the shape and the weight changed.
- **Uniform by construction:** every tool page renders its name through the
  one shared `ToolHeading` component (`ToolHeading.tsx` now renders `rings`
  instead of `waves`), so GPA, CGPA, grade, curve, percentage, tip, loan,
  mortgage, password, quick-grade, and all programmatic tool pages get the
  identical rings with no per-page edits. Info pages (About, Privacy, Terms)
  share the same banner and get the same treatment for consistency.

## Deliberately left alone

- The `waves` variant still exists in `DecorLines.tsx` because the footer
  newsletter card uses it — deleting it would have broken the footer. Only
  the tool-name banner stopped using it.
- Homepage section squiggle underlines, the persona-panel corner arcs, the
  footer divider, and the newsletter plane illustration were not touched:
  they are not tool-name cards. If you want those swapped to rings as well,
  say so and it is a one-line change per usage.
