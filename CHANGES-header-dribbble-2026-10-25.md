# CHANGES — Dribbble-style header (2026-10-25)

Upload the contents of the accompanying zip to the **repo root** (folders
at top level, no wrapper folder), commit, and let the GitHub Action deploy.

## What changed

The site header now follows Dribbble's header layout. This is a
structure-and-style change only: no pages, links, tools or behaviour
were added or removed, and **the primary colour is unchanged** — the
site blue (#0056D2, light mode) and its dark-mode value (#4F9CFF) are
exactly as before. No Dribbble pink (#ea4c89) appears anywhere, and no
Dribbble logo, artwork or content was copied.

New header row, left to right (checked against dribbble.com live):

- Logo (unchanged — same Easy Grade Tool logo and home link).
- Plain-text navigation links in bold, each with a chevron — Grade
  tools, GPA and percentages, Everyday tools — each opening the same
  dropdown menu as before. Previously these were outlined blue chips;
  now they read as simple bold text, like Dribbble's Explore / Hire
  Talent / Get Hired / Community links. The active page's group reads
  in the site blue.
- No search field in the header at the top of the page — exactly like
  Dribbble, whose header only gains its search pill once the page is
  scrolled. Scroll down and a grey filled pill appears between the
  logo and the nav links, with the magnifier inside and the
  placeholder "Search calculators...". The whole pill opens the
  command palette, as before — click, Enter, or typing still hands off
  to the palette, and the Ctrl/⌘K hint is still shown. (No pink search
  button: Dribbble's scrolled search button is hot pink, and the
  primary colour stays untouched.)
- "For Schools" as a plain text link (Dribbble's "Sign up" slot).
- "Quick Grade" as the solid blue pill (Dribbble's "Log in" slot) —
  same colour, same destination (the home page).
- The header is solid white with no bottom border, so it blends into
  the page like Dribbble's, and it stays pinned while scrolling, as
  before. Theme switch and privacy badge: unchanged.
- The row is slightly taller on desktop (80px, was 72px) for the
  airier Dribbble feel. Mobile is unchanged: hamburger, logo, search
  icon, theme switch, same drawer with the same grouped tools (the
  mobile header could not be compared — Dribbble's mobile layout was
  not observable).

Dark mode follows the same tokens as before (blue #4F9CFF, light ink
text, translucent pill backgrounds).
